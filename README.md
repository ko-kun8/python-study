# Python自動化ポートフォリオ

## 自己紹介
Pythonを使った業務自動化・データ収集を得意としています。

## 作ったもの

### 1. Excel自動化（フェーズ1）
- CSVデータ自動集計ツール
- Excelレポート自動生成ツール（グラフ付き）
- PDFからExcelへの変換ツール

### 2. Webスクレイピング（フェーズ2）
- 書籍サイトから60件のデータ収集
- 複数ページの自動巡回・CSV保存
- 画像の自動ダウンロード

### 3. 定型作業自動化（フェーズ3）
- ファイルの自動整理・リネーム
- メール・Slack通知の自動送信
- 日次レポート自動生成ツール

## 使用技術
- Python 3.12+ (または 3.14)
- pandas / openpyxl / matplotlib
- requests / BeautifulSoup / Selenium
- schedule / python-dotenv
